# 瑞雪遇晴天 · 国风互动小剧场

> 一款零依赖的单文件 HTML 互动动画小游戏：讲述两个懵懂单纯的年轻人——**天天**与**瑞瑞**——从相遇、相爱、结婚到生娃的四幕小故事。国潮 Q 版画风，俏皮台词，藏着 6 张"科学小纸条"彩蛋。

![瑞雪遇晴天 · 预览](assets/preview.jpg)

## 试玩

**方式二（GitHub Pages）**：仓库开启 Pages 后，直接访问 `https://<用户名>.github.io/<仓库名>/` 在线玩。

## 游戏内容

| 幕 | 剧情 | 互动小游戏 |
|---|---|---|
| ① 相遇 · 初雪庙会 | 天天排队买糖画，撞上了摊主瑞瑞 | 把被妖风吹落的 3 盏小灯笼拖回挂钩区 |
| ② 相爱 · 一碗汤面 | 放风筝、写歪诗、迟到风波、深夜面摊道歉 | 心跳节拍点击（吊桥效应） |
| ③ 结婚 · 十里红妆 | 新郎官腿打鼓嘴结冰、掀盖头、红烛许愿 | 移动托盘接绣球 + 拜堂三连点 |
| ④ 生娃 · 一颗小星星 | 胎动斗嘴、产房外的转圈、第一次抱娃 | 听胎心节拍 + 给娃取名（有彩蛋） |

- **科学小纸条 ×6**：恋爱脑是真的 / 雪花是六边形限量款 / 吊桥效应 / 公开承诺心理学 / 四十周孕程 / 人生第一声啼哭——右上角"纸"按钮随时回看
- **取名彩蛋**：名字里带"天"或"瑞"会被吐槽；留空默认叫「小满」；取的名字会出现在结尾台词和结算卡上
- **人性点**：紧张笨拙、吵架低头、当众承诺的勇气、第一次抱娃的手忙脚乱——不演完美爱情，演真诚

## 技术实现

- **零依赖**：原生 HTML/CSS/JS 单文件，无引擎、无构建产物依赖、无外部请求；插画以 base64 内嵌，音乐由 WebAudio 实时合成（五声音阶，按幕切换日常/婚礼/摇篮曲三档）
- **舞台**：1280×720 设计稿坐标，`transform: scale()` 自适应任意窗口与手机竖屏
- **剧本引擎**：数组驱动的 beat 系统（`say / choice / note / game / taps / name / danmu / interlude / music / fx / end`），改剧本就是改一个数组
- **进度**：localStorage 自动存档，关掉再开可"继续上次"；纸条图鉴跨周目保留
- **小游戏**：全部基于 Pointer Events（拖拽、跟随、节拍判定），触屏可用

## 目录结构

```
├── index.html            # 构建产物：双击即玩的完整游戏
├── src/
│   ├── game.template.html# 游戏源码（图片为 {{占位符}}，剧本就在这个文件的 SCRIPT 数组里）
│   ├── assemble.py       # 把 assets/ 里的图片转 base64 注入模板 → 生成 index.html
│   ├── recut.py          # 人物立绘抠图（边缘泛洪 + 大连通域保留）
│   └── post_all.py       # 批量后处理：去水印角区、裁剪、压缩（背景 JPEG / 人物 WebP）
├── assets/
│   ├── bg/               # 9 张场景插画（1500×842 JPEG）
│   └── chars/            # 12 张 Q 版人物立绘（820 高、透明底 WebP）
├── docs/prompts.md       # 全部 AI 生图提示词与素材工作流（可复现）
├── LICENSE               # MIT
└── README.md
```

## 本地构建

```bash
# 依赖：Python 3.10+ 与 Pillow（pip install pillow）
python src/assemble.py     # 读 src/game.template.html + assets/ → 输出 index.html
```

## 素材再生成 / 二次创作

- 所有插画由 AI 生成，**完整提示词与处理流程见 [docs/prompts.md](docs/prompts.md)**——想换画风、加角色、加场景，照着提示词重新生成即可
- **改剧本**：打开 `src/game.template.html`，找到 `const SCRIPT = [...]`，加拍/改台词/加选择支都只动这一个数组，然后 `python src/assemble.py` 重新生成
- **改音乐**：`AudioSys.modes` 里三档五声音阶旋律与节奏可随意替换
- 人物立绘为"贴纸风"透明底 WebP，新增角色建议：生成白底全身立绘 → `src/recut.py` 抠图 → `src/post_all.py` 压缩 → 在 `assemble.py` 的映射表里加一行
