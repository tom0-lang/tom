# 素材工作流与全部生图提示词

本项目的全部插画由 AI 文生图/图生图生成，再经本地 Python 流水线清理加工。本文档记录完整的可复现流程与原始提示词，方便你换画风、加角色、加场景。

## 工作流总览

```
① 生图（文生图 / 图生图编辑）
   人物：纯白背景全身立绘（便于抠图）
   场景：无人物宽幅横版（16:9）
        ↓
② 人物抠图：src/recut.py（边缘泛洪 + 羽化 + 大连通域保留，容差 62）
   —— 只保留与边缘连通的近背景色像素，人物内部白色（眼白、袖口、襁褓）不会被误删
        ↓
③ 清理生成器水印 + 压缩：src/post_all.py
   人物：清除右下角水印区（x≥70%w 且 y≥85%h 置透明）→ 按 alpha 裁边 → 高度压到 820px → WebP q88
   背景：右下角水印区用"上方纹理垂直镜像 + 高斯模糊"填补 → 缩到 1500 宽 → JPEG q80
        ↓
④ 注入打包：src/assemble.py
   把 assets/ 全部图片转 base64，替换 src/game.template.html 里的 {{占位符}} → index.html
```

> 生成的小贴士：
> - 人物立绘要求"纯白色背景"，抠图才干净；全身、三头身、正/侧面站姿一次说清
> - 同一角色多表情时，把发型/服装/配饰特征在每条提示词里**完整重复**，一致性最好
> - 部分生成器会给图片右下角加水印，人物图会被抠图步骤+水印区清除顺带解决，背景图用镜像填补

## 非生成素材

- 游戏内小灯笼、绣球、托盘、心跳爱心均为手写内联 SVG（见 `src/game.template.html`）
- 音乐无采样：WebAudio 实时合成，C 宫五声音阶（C D E G A）三角波拨弦 + 低音铺底，旋律序列在 `AudioSys.modes`
