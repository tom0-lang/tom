  这是个task 2的原创游戏。人物名字是我和老婆。作为一个不会代码是IT人，此作品谨送给最爱的老婆。

其实上次task已经在duckduckgo的所谓的GPT 6里面测试了，但是上下文限制没有完成。而且我觉得生成的效果一般般。
因为autoclaw送积分，积分还多，就试一试。没想到效果很惊艳。主要是前面第一步 生成国风的图片就很好。比上次的GPT的纯2D渲染的HTML好很多。当然另一方面可能也是因为那个是“2D绘本”游戏。
因为不满意，我特意在autoglm里面说了是"2D动画"游戏，要国风动画，那自然效果会好一点。而且autoglm使用的素材一看就很熟悉，很亲切，游戏背景也很好，感觉达到了一定的动画师的级别，还是自家模型更地道，更加符合咱的口味啊。
再加上缓慢悠扬的国风音乐🎵，真的很喜欢啊啊啊
注意，敲完上面这段话，只是 第一个步骤哦，还在显示1/5步。

至此，游戏风格，动画效果已经很令人满意的了。做出这种让人基本满意的小游戏，以前动画师估计也得花时间，得花钱，还得写代码。现在完全用国产agent+国产大模型，免费积分，就完成了，这就是生在好时代。
话又说回来了，大模型训练的时候，游戏素材，游戏设计，图片生成，代码补全应该都是涉及到的，这个任务对他来说可能都只是属于普通难度。所以更感觉到了大模型的强大。

有一个细节，agent生图的时候，先是有水印“z.ai”的，然后大模型自己就写脚本清除了水印，很智能了，没有喧宾夺主。不过不知道是不是有数字水印呢？

而这，只是GLM 5.3 flash的水平。智谱还是有两下子的。贼code，你还是有可取之处的。
任务使用了agent集群。但是没有开“目标”选项。
最新更新的autoclaw还加上了"工作流"选项。
AI与工作流这块值得说道说道。扣子企业版的工作流因为大模型的自主规划能力的强大而下线。而今agent主动把传统工作流纳入能力范畴。AI的自主性 与 工作流的流程严谨性有矛盾本之处，但是也可以相结合相符相成，通过流程的严谨性来一定程度上规避模型的幻觉与上下文记忆等方面导致的偏差。（以上纯属纸上谈兵）

说完优点说缺点。 让我验收人物，我说女主角的腿和脚可以更加美丽可爱一些，前面还画风正常 画面一多，后面生成的图片女主就变成了去年电影🎞中的哪吒了，简直一模一样。不知道这个是不是所谓的训练过程中的“过拟合”?
